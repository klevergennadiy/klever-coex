ВАРИАНТ 1. PDF → редактируемые фреймы (быстрее всего)
Папка 01_Figma_PDF. Перетащите PDF в файл Figma Design (или Файл → Импорт).
Каждая страница PDF = отдельный фрейм в точном размере носителя: 1 pt = 1 px
(слайды 1920×1080, каталог 595×842, сайт 1440, пост 1080×1350 и т. д.).
Текст остаётся текстом. Сводные PDF по разделам лежат рядом с папками,
по одному шаблону — внутри папок.
Минус: слои без auto-layout, группы плоские.

ВАРИАНТ 2. HTML → слои с auto-layout (точнее по структуре)
Папка 02_Figma_HTML. Нужен плагин html.to.design (Figma Community).
В плагине выберите импорт файла и загрузите нужный .html.
Шрифты подтягиваются из установленных; логотипы вшиты в файлы.
Сетки и отступы собраны на flex/grid — плагин переводит их в auto-layout.

ТОКЕНЫ → ПЕРЕМЕННЫЕ И СТИЛИ FIGMA
Папка 03_Tokens:
  tokens-studio.json — для плагина Tokens Studio: наборы core / light / dark,
    две темы, цвета, отступы, радиусы, типографика. Плагин создаёт Variables и Text Styles.
