# Клевер COEX — дизайн-система

![Клевер COEX](images/hero/catalog-cover-crosses.jpg)

Сайт: включите GitHub Pages (Settings → Pages → main / root) и откройте `https://<логин>.github.io/klever-coex/`.

| Папка | Что внутри |
|---|---|
| `index.html` | Витрина дизайн-системы |
| `templates/` | 110+ шаблонов живыми HTML-страницами (импорт в Figma через html.to.design) |
| `figma-pdf/` | Те же шаблоны в PDF, 1 px = 1 pt — перетащить в Figma |
| `previews/` | Превью шаблонов |
| `pptx/` | Презентации и каталог A4 в PowerPoint |
| `tokens/` | Токены: Tokens Studio, Figma Variables (DTCG), CSS |
| `logos/` | Логотипы: рабочие SVG и полный официальный набор |
| `fonts/` | Inter Display, Geist Mono + лицензии |
| `images/` | Продуктовые фото (PNG/WebP с прозрачностью), атмосферные кадры, имидж |
| `graphics/` | Призрачные названия линеек (SVG) |
| `icons/` | Временный набор иконок |
| `guide/` | Руководство по фирменному стилю v.1 |
